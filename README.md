# 心晴同行：SEN 訓練中心

這是一個以香港繁體中文編寫的**純靜態** SEN 教學活動網站，主要供作者自用、課堂帶領及公開示範。網站不設帳戶、後端、資料庫、雲端學生紀錄、分析追蹤或咪高峰錄音上傳。

> 活動結果只作當前練習和教學帶領參考，不作診斷、能力比較、升學、就業或任何正式評估。

## 使用方式

直接開啟 `index.html`，或以任何靜態 HTTP 伺服器載入專案根目錄。建議使用最新版 Chrome、Edge、Firefox 或 Safari。核心活動設計為可用滑鼠／觸控及鍵盤操作；朗讀功能取決於裝置提供的語音合成。

課堂模式的完成、提示與重試摘要只會寫入目前瀏覽器的 `localStorage`，鍵名為 `sen-classroom-session-v1`。共用電腦或平板交給下一位使用者前，請按首頁課堂控制中的 **「清除本機紀錄」**。

## 不可加入的功能

公開自用版不得加入登入、密碼、學生姓名、學生識別碼、雲端同步、資料庫、分析像素、第三方追蹤、咪高峰錄音或任何上傳學生作品的功能。若日後確實需要這些能力，必須先另行進行私隱、保安、家長／學校授權與發布設計審核。

## 每次公開發布的最小流程

| 次序 | 操作 | 通過標準 |
| --- | --- | --- |
| 1 | 檢查 `git status --short` | 不包含測試 JSON、截圖、學生資料、密鑰或私人檔案。 |
| 2 | 執行 `node --check assets/js/sen-app.js` 與已修改模組 | 所有已修改 JavaScript 均無語法錯誤。 |
| 3 | 執行相應的 `scripts/audit-*.mjs` | 修改範圍的回歸結果為零失敗。 |
| 4 | 更新首頁版本標記及已修改 JS 的 `?v=` 參數 | 公開訪客不會載入舊快取模組。 |
| 5 | 推送 GitHub 後，以無痕視窗和手機網絡開啟首頁及已修改入口 | 版本號正確、頁面能載入、可開啟一項活動並安全離開。 |
| 6 | 記錄提交 hash 和上一個穩定提交 | 可在需要時立即回退。 |

## 回退

先確認要回到的已驗證提交，再建立一個新的回退提交，避免直接改寫公開歷史：

```bash
git revert <需要撤銷的提交>
git push origin main
```

如因多個提交需要回退，應先在本機／測試環境驗證，再按由新至舊的順序執行 `git revert`。發布後重做無痕冒煙檢查。

## 不可隨意修改的檔案

| 檔案／範圍 | 原因 |
| --- | --- |
| `modules/eight-round-normalizer.js` | 會影響全站少於八關資料的呈現；改動前必須重新做唯一性稽核。 |
| `assets/js/sen-app.js` | 處理主路由、計分、課堂摘要、Escape 與焦點回復。 |
| `assets/js/sen-interaction-layer.js` | 處理共用互動與可及性行為。 |
| `scripts/audit-*.mjs` | 是發布前驗證依據；修改時要記錄原有測試規格及新規格。 |
| HTML 的 JS `?v=` 參數 | 用於避免 GitHub Pages／瀏覽器公開快取載入舊模組。 |

## 公開內容檢查

公開前不得提交學生姓名、電話、電郵、地址、學校內部資料、學生截圖、音檔、授權不明媒體、API key、token、密碼或 `.env` 檔。發布後亦應在 GitHub 網頁查看檔案清單，確認沒有意外上傳的測試輸出或私人附件。
